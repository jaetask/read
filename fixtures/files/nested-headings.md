# Harbor Kit: nested sample

Jan 2, 2026 · @Tester

A made-up toolkit, written only for Talk's tests. Nothing here describes real software.

## Getting started

Install Harbor Kit, then open the dashboard. The first run creates a small example project.

### Requirements

You need a recent laptop and about one gigabyte of free space.

#### Supported systems

Harbor Kit runs on macOS and Linux. Windows is not supported yet.

#### Overview

This overview covers setup only. Read it before installing.

## Tools

Harbor Kit has three tools: a planner, a runner and a viewer.

### The planner

The planner turns a goal into a list of steps.

#### Overview

The planner overview explains how steps are ordered by their dependencies.

#### Retry rules

A failed step is retried twice, then the plan stops and asks a person.

## Wrap up

That is the whole sample. It exists so tests can jump to deep headings.
